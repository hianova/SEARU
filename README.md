# SEARU: The Universal Generative Design & R&D Suite

## 核心理念 (Core Philosophy)

SEARU 是一個通用的**「生成式設計與研發輔助引擎」**。
我們的終極目標是**「跨領域降低設計與研發的複雜度 (Reduce Design and R&D Complexity)」**。

無論是軟體架構、音樂藝術、視覺幾何，甚至是物理機構與材料力學，設計的本質往往是「在龐大的參數空間中尋找最優解」。傳統的研發依賴長時間的試錯與人力微調；SEARU 改變了這個範式：它將設計參數（和弦、幾何尺寸、物理邊界條件）視為「基因 (Genes)」。

透過繼承自編譯器與最佳化領域的強大核心（例如 The Crucible 的蒙地卡羅退火、Z3 定理證明器），SEARU 能夠在數學層面上，為任何領域「發明」與「計算」出最完美的結構。讓創作者與工程師從繁瑣的旋鈕海洋與盲目試驗中解放，專注於定義美學、物理邊界與高階約束。

## 為什麼需要 SEARU？

1. **從盲目試錯到數學收斂**：不管是尋找最和諧的泛音列，還是最穩固的桁架結構，SEARU 都能瞬間退火計算出符合邊界條件的最佳解。
2. **跨領域的研發大腦**：音樂只是 SEARU 的第一個試驗場 (`music` 模組)。這套退火與求解引擎可以毫無阻礙地套用在視覺藝術 (`visual`)、機械結構 (`mechanics`) 等任何可以用數學建模的領域。
3. **藝術、工程與科學的交點**：將蒙地卡羅演算法與約束求解器，化為人類創造力的最強延伸。

## 專案目錄與未來藍圖

目前的 SEARU 包含了核心科學大腦 (`science`)，並且已經開闢了多個設計領域的實驗場域：

- `src/science/` (The Core Engine)
  - **核心演算大腦**：包含 `The Crucible` (退火與求解器) 與 `Chaos State`，所有跨領域的演化都在這裡發生。
- `src/music/` (Proof of Concept 1)
  - **生成式音樂**：將音階與泛音模型化。內部包含 `dsp` (數位訊號處理)、`arrangement` (曲式張力演化)、`midi` 與 `vst` 等專屬音樂應用的子模組。
- `src/visual/` 
  - **視覺幾何與圖形**：未來將探索生成式圖形、幾何拓撲優化、動態流體視覺，將參數化設計推向極致。
- `src/mechanics/` 
  - **機構與結構設計**：為實體物件尋找最佳的應力分佈或連桿軌跡，降低物理原型的試錯成本。
- `src/materials/` 
  - **材質與光學**：演化物理渲染 (PBR) 參數或材質組合，尋找特定的折射率或視覺質地。

## 快速上手

```bash
cargo run
```
目前，執行後 SEARU 會啟動其 `music` 模組的作曲家，點燃 Crucible 在微秒級別的時間內，從聲學定律中「計算」出最完美的和弦結構！這只是冰山一角，更多的設計領域即將解鎖。
