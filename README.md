# 🚀 SEARU Studio
> **「用最簡單的程式碼，即時創造你的 3D 結構與專屬電子配樂！」**

只要調整幾個數字或寫 4 行白話程式碼，電腦就會自動算出 3D 建築結構，並同步創作出一首專屬的電子音樂！

這就是 **SEARU** —— 一個結合「空間力學演化」與「真實聲學合成」的跨領域生成引擎。你不需要會複雜的 3D 建模軟體，也不需要學會樂理，只要寫幾行 **SearuScript**，就能體驗當造物主的樂趣！

---

## 🎮 4 大專屬工作區

### 1. ✨ Synesthesia (五感共鳴引擎)
輸入四個直覺的設計風格：
- **侵略性 (`Aggression`)**：幾何的張力、音樂的失真與節奏力道。
- **優雅度 (`Elegance`)**：結構的對稱性、旋律的古典和諧美。
- **結構密度 (`Density`)**：網格與房間的密集度、聲部細分度。
- **工業感 (`Industrialism`)**：鋼構金屬質感、FM 電子音色強弱。
👉 **按下執行，不到一秒鐘，左邊呈現 3D 模型，右邊即刻播放專屬配樂！**

### 2. 🎧 Music Studio (音樂工作室)
內建古典對位法與 Plomp-Levelt 聲學模型，自動尋找最和諧的和弦進行與 FM 音色。

### 3. 🏛️ Architecture (建築與力學)
在背景計算空間利用率、重力受力分佈與動態風阻，自動演化出最佳 2D/3D 平面與桁架結構。

### 4. 💿 Album Release (一鍵發專輯)
調用多核心平行運算，一次批次生產 10 首完整的電子音樂軌並提供試聽下載。

## ⚡ 什麼是 SearuScript？
打開左側編輯器，輸入最簡單的程式碼：

```javascript
// 創造一座狂暴且密集的重金屬工業風格
let aggression: Float = 95.0;     // 侵略性
let elegance: Float = 5.0;        // 優雅度
let density: Float = 90.0;        // 結構密度
let industrialism: Float = 80.0;   // 工業感
```

勾選 **⚡ Auto Hot-Load**，只要在鍵盤上改數字，3D 模型與音樂就會自動即時更新！
